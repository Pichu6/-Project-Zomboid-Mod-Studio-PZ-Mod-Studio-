Add what you know

A registry is one small JSON file per mod, by pull request; the repository's check refuses a malformed one, so a person reviews only what a machine could not. From the Studio: right-click a mod → Share what the Studio saw of this mod… opens GitHub with the file filled in. Without git: report a mod issue with the form, and a maintainer files it.
